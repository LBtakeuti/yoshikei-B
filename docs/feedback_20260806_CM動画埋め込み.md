作業前に必ず `git pull`。1タスク=1コミット。

## 仕様

1. 位置：未ログイン雑誌型トップの**「ご利用の流れ」セクションの直後**（エリアバナーやメニュー棚の並びは崩さない。ご利用の流れ→CM→以降は現状の順）
2. レイアウト：**SP・PCとも2本を上下（縦積み）に配置**（竹内さん指示：PCは上と下）。PCは幅640px程度で中央寄せ、SPはコンテンツ幅いっぱい。各動画は16:9
3. 見た目・実装は**ファサード方式**（軽さ優先）：
   - 初期表示は `https://i.ytimg.com/vi/<ID>/hqdefault.jpg` のサムネイル画像＋中央に赤い再生ボタン（YouTube風の角丸長方形＋白三角のSVG。絵文字禁止）
   - クリックで同じ枠を YouTube iframe（`https://www.youtube.com/embed/<ID>?autoplay=1`）に差し替えて再生
   - これによりページ読み込み時にYouTubeのスクリプトを読まず、モックの軽さを維持
4. 各動画の下（または上）にタイトル1行：「ヨシケイ2025秋新CM「登場」篇 30秒」／「ヨシケイ2025秋新CM「献立決め」篇 15秒」（小さめ・#6f6f6f）
5. セクション見出し：「テレビCM放映中」（既存セクション見出しのスタイルに合わせる）
6. **差分描画（morph）との整合（重要）**：
   - セクションに `data-mk="cmsec"` を付与
   - クリックでiframe化した後、再描画でサムネイルに巻き戻らないこと。再生状態を `S` か静的DOM側で保持する（エリア確認モーダルと同じ「再描画対象外の静的DOM」に置くか、状態フラグでiframeを再出力する）
7. 未ログイン時のみ表示（雑誌型トップ限定。フルメニュー表示・ログイン後には出さない）

## 検証観点（実装後に自分でも確認）

- SP/PCとも「ご利用の流れ」の直後にCM2本が上下に並ぶ
- サムネイル→クリックで再生（iframeに切替）。もう1本も独立して再生できる
- 再生中にカート反映などの再描画をしても動画が止まらない・巻き戻らない
- 初期表示でYouTubeのiframeが読み込まれていない（facadeが効いている）
- 横スクロールなし・既存セクションのレイアウト崩れなし
