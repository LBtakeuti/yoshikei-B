# FB 2026-08-04：ECヒーローの組み込みとゲスト閲覧モード（乖離リストNo.1の第一歩）

## 目的
本体（index.html）を「会員でなくても商品を見られる」ECトップにする第一歩。未ログインでも注文TOPを閲覧でき、最上部にヒーローセクション（claude.ai/designで作成済み）を表示する。

## 作業内容（1コミット=1論理変更で分けてよい）

### 1. ゲスト閲覧の解放
- index.html 末尾のゲート処理（`location.replace('lp.html')`）を変更：**未ログインでもリダイレクトせず注文TOPを表示**する。`?login=1` 付きのときだけ従来どおりログインモーダルを自動表示。
- ログアウト時の `location.href='lp.html'` は現状維持でよい。
- 未ログイン時にマイページ・注文確定など会員限定操作をした場合は、既存の `Login.open()` ガードが働くこと（既にある `if(!S.loggedIn){Login.open();return;}` を壊さない）。

### 2. ヒーローセクションの表示（未ログイン時のみ）
- `docs/snippets/ec_hero_section.html` を読み、(1)のCSSを `<head>` の style に追加、(2)のHTMLをテンプレート文字列化して **SP・PC両方の注文TOP描画の最上部（ヘッダー直下）** に `!S.loggedIn` のときだけ挿入する。
- `{{WEEK}}`・`{{DEADLINE}}` は既存の週状態（現在選択中の週の表示文字列・締切日）から生成する。既存で週や締切のテキストを組み立てている箇所があればそれを再利用し、なければ既存モックの週表記に合わせた固定値でよい（例：`5/11`週・`締切：5/6(水) 23:59`）。書式は「M/D週のご注文受付中」「締切：M/D(水) 23:59」。
- ログイン済みのときはヒーローを出さない（既存の画面のまま）。

### 3. ヘッダーの「ログイン／はじめての方」
- **PC ヘッダー右側**：未ログイン時「ログイン」（赤塗り）＋「はじめての方」（白地赤枠）。**ログイン済みでも「はじめての方」は表示を維持**する（ユーザー指示）。
- **SP ヘッダー右側**：ハンバーガーボタン（三本線アイコン・SVG）を追加し、タップで簡易メニューを開閉。メニュー項目＝「ログイン」（未ログイン時のみ）／「はじめての方」（常時）。画面に浮かせる常設ボタンは作らない。
- ボタンの動作：「ログイン」→ `Login.open()`。「はじめての方」→ 既存の仮登録フロー入口（ログインモーダル内の「はじめての方」ボタンと同じ処理）を直接起動する。
- 絵文字・装飾記号は使わない（SVGのみ）。

## 検証観点（実装後にこちらでE2Eも回します）
- 未ログインで index.html を直接開く → リダイレクトされずヒーロー＋メニューが見える
- `?login=1` → 従来どおりモーダル自動表示
- ログインするとヒーローが消える／ログアウトでLPへ
- 390px幅でヒーローが崩れない・ハンバーガーが動く
