# 実装指示：注文確定→未ログイン時の「お客様情報の登録に進む」導線（2026-08-06）

対象：`index.html`。
竹内さんFB：未ログインで「注文を確定する」を押すとログイン/質問つき登録が選べるが、その下に暫定で**「お客様情報の登録に進む」**を追加。顧客に必要なフォーム→**仮審査中**（受付番号・「審査が通りましたらメールにてお知らせいたします。目安は〇〇日」・お問い合わせ先）まで通す。

## 実装内容

1. **ログインモーダルに3つ目の入口を追加**：ログイン／無料ではじめる（7つの質問）の下にテキストリンク風の「お客様情報の登録に進む」（data-register-start）
2. **Login.register()（質問スキップの直行モード direct=true）**
   - エリア確認モーダルで確認済み（rk_area_checked）なら、rk_area_zip を judgeZip で再判定して**郵便番号入力も飛ばして顧客情報フォームから開始**（郵便番号は転記済み）
   - 未確認なら郵便番号確認から。エリア内画面のボタンは「質問に進む」→**「お客様情報の入力に進む」**に変わる
3. **顧客情報フォームは既存の仮登録フォームを共用**（KOKYAKU対応：氏名・フリガナ・郵便番号・住所・電話・メール・パスワード必須／生年月日・家族人数・紹介者コード任意。家族人数の既定は大人2・子0）
4. **完了画面を仮審査中仕様に**：
   - 「仮登録が完了しました」＋バッジ**「ただいま仮審査中です」**
   - 受付番号を枠で強調（R-260730-001）
   - 「審査が通りましたら、メールにてお知らせいたします。**目安は2〜3営業日です。**」（日数は文言1箇所で変更可）
   - お問い合わせ先＝地域別フリーダイヤル（regionTelHTML・富山石川0120-25-3711／岐阜0120-85-4441）
   - 「メニューを見る」→ようこそ演出→仮登録（provisional）としてログイン成立。カートは維持
5. 従来の7つの質問つきフロー（無料ではじめる）はそのまま並存

## 検証観点

- エリア確認済みゲスト：カート→注文確定→モーダルに新リンク→クリックでフォーム直行（郵便番号転記・質問なし）→仮登録→仮審査中画面（受付番号/メール案内/目安/フリーダイヤル）→メニューを見るでprovisionalログイン・カート維持
- エリア未確認ゲスト：新リンク→郵便番号確認→「お客様情報の入力に進む」→フォーム
- pageerror 0
