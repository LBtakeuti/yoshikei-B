# 実装指示：「今週のメニューをすべて見る」切替のUX段階化（2026-08-06）

対象：`index.html`。
竹内さんFB：すべて見るを押すと、タブ（シリーズから選択/配達日から選択）やカートがいきなり出てきて別ページに飛んだように見える。タブは表示してよいが、カートまで一気に出るのは変わりすぎ。UXを工夫する。

## 実装内容

1. **ゲストの初期カートを空に**：デモ用の3品（S.cartItems初期値）が未ログインでも入っていたのが「カートがいきなり出てくる」の主因。ゲストは空カートで開始し、デモ3品は**既存会員としてログイン成立した時にだけ投入**（DEMO_CART・completeLogin。仮登録=新規や、ゲストが自分で入れた商品がある場合は上書きしない）
2. **PC右レールのミニカートは段階表示**：ゲスト×カート空の間は非表示。商品を選んだ瞬間から現れる（S.loggedIn||cartItems.length>0）
3. **切替先の冒頭に案内ヘッダー**：「トップに戻る」＋見出し「今週のメニュー一覧」＋説明1行（PCは「カートはメニューを選ぶと右側に表示されます」を付記）。別ページ感をなくし文脈をつなぐ
4. タブ・検索・絞り込み・週セレクタは従来どおり表示（竹内さん了承済み）

## 検証観点

- ゲストで「すべて見る」→ 右レールなし・カート0点・案内見出しあり
- エリア確認済みゲストが商品追加 → 右レール出現（1点〜）
- 既存会員ログイン → デモ3品がカートに入る（カート画面・締切リマインドのデモ維持）
- pageerror 0
