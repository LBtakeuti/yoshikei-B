# 実装指示：「今週のメニューをすべて見る」を別ページ遷移に変更（2026-08-06）

対象：`index.html`。
竹内さんFB：すべて見るでその場のタブ展開だとユーザーが混乱する。**別ページに移動させる**。注文ページはログイン後の画面とほとんど同じで、カート反映時にお届け範囲の確認や会員登録のフローが発生する形。

## 実装内容

1. **擬似ルーティング `#menu`**（本番では /menu 等の別ルート想定）
   - 「すべて見る」（棚下ボタン・ヒーローCTA）で `location.hash='menu'` を積んで別ページとして表示。スクロールは先頭へ
   - `hashchange` 監視で**ブラウザの戻る/進むに対応**（戻る→雑誌型トップ／進む→メニューページ）
   - `index.html#menu` の**直リンクでもメニューページが開く**
   - 「トップに戻る」は `replaceState` でハッシュを消して雑誌型トップへ
2. **メニューページの構成**＝ログイン後トップとほぼ同じ（タブ・検索・絞り込み・週セレクタ・商品リスト）。冒頭に「トップに戻る＋今週のメニュー一覧＋説明1行」のページヘッダー。**ヒーロー・カルーセル・雑誌型セクションは出さない**（別ページなので）
3. カート反映時の**エリア確認→会員登録フローは従来どおり**発生（rk_area_checked未確認ならモーダル起動）
4. 段階表示（ゲスト空カート・PCミニカートは商品選択後に出現）は前回実装のまま有効

## 検証観点

- すべて見る→URLが#menuになり、ヒーローなし・ページヘッダーあり・タブありの別ページ表示
- ブラウザ戻る→雑誌型トップ（ヒーロー・棚）／進む→メニューページ復帰
- #menu直リンクで開ける。未確認ゲストのカート反映でエリア確認モーダル
- pageerror 0
