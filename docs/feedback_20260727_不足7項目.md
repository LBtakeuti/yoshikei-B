# 実装指示：合意済み仕様との差分7項目（2026-07-27）

対象：`index.html` のみ。`lp.html`・`src/` は触らない。
根拠：お客様との合意事項（7/16・7/23定例、要望シート）とモックの照合結果。

## 共通ルール（必ず守ること）

- 絵文字・装飾記号（♥・★・→等）を一切使わない。アイコンは既存の `IC.◯◯` SVG群に追加する形で作る
- 既存のデザイントークンを踏襲：赤 #E50012、カード角丸12px、影 0 1px 5px rgba(0,0,0,.10)、フォントサイズの流儀
- 既存機能（週切替・検索・お気に入り・カート・注文フロー・マイページ）を壊さない
- 1タスク＝1コミット。日本語メッセージ・prefix付き（feat:/fix:/style:）
- 価格計算に触れる箇所は、文字列価格（'1,350'）を数値に直してから計算し、表示時にカンマ整形する

## タスク1：通し割引の表示と計算（最優先。No.56・7/23合意）

- ルール：**同じ料理**（カートアイテムの title が同じ）を**5日分以上**注文すると通し割引が適用される。人数違い・カットあり/なしの混在でも同一料理なら対象（お客様確定仕様）
- モックでの割引額はダミーでよい：対象商品の合計の5%（10円未満切り捨て）
- 表示場所（4箇所）：カートパネル／注文確認画面／注文完了画面／注文履歴。「通し割引 -◯◯円」の行を小計と合計の間に赤字で追加
- まとめて購入セットのモーダルにも「5日間まとめてのご注文で通し割引が適用されます」の一文と割引後価格を表示
- コミット：`feat: 通し割引の計算と明示表示（カート・確認・完了・履歴）`

## タスク4：オンボーディング先頭にエリア判定ステップを追加（7/23合意）

- 7つの質問の前に「ステップ0」を挿入：見出し「お住まいの地域を教えてください」＋説明「お届けできる地域かご確認します」
- 郵便番号入力：数字7桁。ハイフン自動除去。7桁未満は「確認する」無効
- 判定はダミーデータ（先頭3桁）。後で町名粒度に差し替えるためデータは分離：

```js
const AREA_ZIPS=[
  {prefix:'930',office:'富山営業所'},{prefix:'933',office:'高岡営業所'},
  {prefix:'920',office:'金沢営業所'},{prefix:'921',office:'金沢南営業所'},
  {prefix:'500',office:'岐阜営業所'},{prefix:'501',office:'岐阜西営業所'},
];
```

- エリア内：「お届けエリアです（担当：◯◯営業所）」を表示して質問1へ。営業所名は状態に保持
- エリア外：ガイド画面「申し訳ございません。ご入力の地域は当社のお届けエリア外です」＋「お住まいの地域は別のヨシケイが担当している場合があります」＋ボタン「お近くのヨシケイを探す」（ダミー）＋「フリーダイヤル 0120-XXX-XXX」＋「郵便番号を入力し直す」リンク
- 動作確認例：エリア内 9300001／エリア外 1000001
- コミット：`feat: 登録フロー先頭に郵便番号エリア判定と管轄外ガイドを追加`
