# FB 2026-08-05：雑誌型ゲストトップ（B案確定）とバナーカルーセル

## 目的
未ログインの注文TOP（index.html）を「雑誌型」の段階構成にする（ユーザー決定・B案）。
構成＝ ヒーロー → **バナーカルーセル** → ご利用の流れ（デザイン到着待ちのプレースホルダー） → 今週のメニュー棚 → 「今週のメニューをすべて見る」→ フルメニュー画面。
バナーは**将来管理画面から横長画像を入稿する前提**のデータ駆動カルーセルとして作る（遷移先は外部ページ／ページ内ディープリンクの両対応）。

## 作業1：バナーカルーセルセクション（未ログイン時のみ・ヒーロー直下）
- データ定義を `WEEKS` の近くに追加（管理画面入稿を想定したデータ形。これがそのままAPI/CMSの器になる想定）：
  ```js
  const BANNERS=[
    {id:'trial',  img:null, label:'初回限定 お試しキャンペーン実施中', sub:'対象コースが最大50%OFF', href:'lp.html#trial-campaign', theme:'red'},
    {id:'shelf',  img:null, label:'今週のメニューをのぞいてみる',     sub:'管理栄養士監修の献立',   href:'#guest-shelf',           theme:'green'},
    {id:'coin',   img:null, label:'eコインでおトクに続ける',          sub:'週2,160円以上で貯まる',  href:'#',                      theme:'gold'}
  ];
  ```
- `img` が入ればその画像を表示、`null` ならモック用のプレースホルダーバナー（テーマ色のグラデーション帯＋label/sub のテキスト）を描画する。「ここに管理画面から入稿した横長画像が入る」ことが見て分かる見た目にする。
- 遷移仕様：`href` が `#` 始まり→ページ内アンカーへスムーズスクロール（ディープリンク）。それ以外→通常遷移。`#` 単体はダミー（何もしないかトースト）。
- UI仕様：
  - 横長バナー（アスペクト比はSPで約 21:9、PCで約 4:1）。左右に少し次のバナーが見える peek 付きの scroll-snap カルーセル。
  - ドットインジケーター（現在位置ハイライト）／5秒で自動送り（ユーザーがスワイプ・タップしたら自動送り停止）／PCは左右矢印ボタン（SVG）。
  - 絵文字・装飾記号は使わない（SVGのみ）。角丸・余白は既存モックのトーンに合わせる。

## 作業2：ゲストトップのB構成化（未ログイン時のみ）
- 未ログイン時の注文TOPを次の順に：
  1. ヒーロー（既存）
  2. バナーカルーセル（作業1）
  3. ご利用の流れ：`ph-box` を使ったプレースホルダー帯（見出し「ご利用の流れ」＋「デザイン準備中」表記。後日 claude.ai/design 版に差し替え予定）
  4. **今週のメニュー棚**（`id="guest-shelf"`）：見出し「今週のメニュー」＋現在週の商品から6品を横スクロールで表示。価格は見せる。ボタンは**「詳しく見る」のみ**（既存の商品詳細を開く）。**カート投入ボタン・数量ボタンは置かない**。
  5. 「今週のメニューをすべて見る」ボタン（大きめ・中央）→ 押すとフルメニュー表示（現行のゲスト用注文TOP＝週タブ＋一覧）にリロードなしで切り替え（例：`S.guestFull=true` で再描画）。戻る導線として、フル表示側の上部に「トップに戻る」リンクを付ける。
- フルメニュー表示に切り替えた後も、未ログインである限りヒーローとカルーセルは上部に残してよい（棚と流れは非表示にしてよい）。
- ログイン済みの画面は一切変えない。SP・PC両対応。

## 検証観点（実装後にE2Eも回します）
- 未ログインで開く → ヒーロー→カルーセル→流れ(プレースホルダー)→棚→「すべて見る」の順に並ぶ
- カルーセル：スワイプ・ドット・自動送り・PC矢印が動く／「#guest-shelf」バナーで棚へスクロール／「lp.html#trial-campaign」バナーでLPのお試しセクションへ
- 棚：6品・価格表示・「詳しく見る」で詳細が開く・カート投入UIがない
- 「すべて見る」→ フルメニューに切替、リロードなし、「トップに戻る」で戻れる
- ログインすると従来画面（雑誌型は出ない）／390px幅で崩れ・横スクロールなし
