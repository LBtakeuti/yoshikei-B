# 実装指示：ヒーロー角丸カード化・カルーセル並び表示・今週のメニュー先頭化（2026-08-06）

対象：`index.html`。竹内さん指示3点（参考：メディア・ワーク社サイトのヒーロー）。

## 1. ヒーローセクションを角丸カードでマスク

- 全幅ベタ置きをやめ、白地の上に**角丸の長方形カード**として載せる（参考画像のように四辺に余白）
- SP：左右12px余白・角丸18px／PC：左右24px余白・角丸22px・最大幅1200px中央寄せ
- 4枚クロスフェード・文言・CTAは変更なし（カード内にそのまま収める）

## 2. バナーカルーセルは「切り替え」ではなく「並び」表示

- 前回のフェード切り替えはヒーロー側の参考だった（認識訂正）。バナーは**スライドが横に並ぶカルーセル**に戻す
- SP：1枚表示（先頭スナップ）／**PC：1枚目＋2枚目が半分ほど見える**（スライド幅60%・約720px・2:1維持）
- エリア確認バナー先頭スライド・クリックでArea.open()・確認済みで除外・2:1・ドット/矢印/自動送り5秒/スワイプは維持
- スナップは中央寄せではなく**先頭寄せ**（1枚目が左、2枚目が右にのぞく見え方）

## 3. 雑誌型トップの順序変更：今週のメニューを最上段へ

新しい順序（SP/PC共通）：
1. ヒーロー
2. バナーカルーセル
3. **今週のメニュー棚＋すべて見る**（商品=閲覧・比較の起点。来訪者の最大の関心「今週なにが届くか」に最短で答える）
4. ご利用の流れ（メニューに興味を持った人の次の疑問「どう頼む・どう届く」に答える）
5. （PCのみ）エリア確認バナー（流れを理解した直後の行動喚起）
6. テレビCM（信頼・ブランドの補強。最下段）

根拠：新サイトの目的ファネル「閲覧→比較→検討→申込」に沿わせる。メニュー=閲覧・比較の材料、流れ・エリア=検討→申込の後押し、CM=信頼形成、の順。

## 検証観点

- SP/PCともヒーローが角丸カード・クロスフェード継続
- PCでバナー2枚目が右にのぞく。矢印/ドット/自動送り/先頭スライド→モーダル/確認後除外の回帰
- 棚→流れ→（エリア）→CMの順。横スクロールなし・pageerror 0
