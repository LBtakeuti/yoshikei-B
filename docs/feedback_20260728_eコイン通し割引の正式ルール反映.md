# 実装指示：eコイン・通し割引を正式ルールに修正（2026-07-28）

対象：`index.html` のみ。
根拠：お客様提供「ヨシケイ_簡易要件定義書.xlsx」（01_サービス概要・04_eコイン要件）で正式ルールが確定したため、モックの実装を合わせる。

## 共通ルール

- 絵文字・装飾記号禁止。既存デザイントークン・IC SVG群を踏襲
- 既存機能を壊さない。1タスク=1コミット（日本語・prefix付き）
- 価格は数値で計算し表示時にカンマ整形

## 前提：カートアイテムへの属性追加（両タスクの土台）

現在のカートアイテムは `{title, tag, unit, price, qty, week}` だが、正式ルールの判定には不足。以下2属性を追加する：

- `day`：お届け曜日/日付（例 '5/11'。どの日の献立かを識別）
- `cat`：出自カテゴリ（'smile' | 'more' | 'lovyu' | 'tanpin' | 'special'）。CATALOG/SPECIALS のどこから入ったかを保持

すべてのカート投入経路（商品詳細モーダル・まとめて購入・合わせ買いレコメンド・もう一品）で両属性を設定すること。初期データのcartItemsにも付与する。

## タスク1：eコイン付与を正式ルールに修正

現状：`coinFor(total) = total>=2160 ? floor(total/100) : 0`（100円ごと1pt・全商品対象）
正式ルール：

1. **付与対象の金額** = カート内の `cat` が smile / more / lovyu の商品合計のみ（**tanpin（単品・冷凍食品）と special（特別販売）は付与対象外**）
2. 対象金額が **2,160円(税込)以上** の場合のみ付与
3. 付与数 = **対象金額 ÷ 108円 の切り捨て**（108円(税込)ごとに1コイン）

- 表示箇所（カート・注文完了・履歴の獲得コイン表示）はこの計算結果に置き換える
- 獲得コイン表示の近くに小さな注記「対象商品2,160円以上のご注文で108円ごとに1コイン（特別販売は対象外）」を追加
- コミット：`fix: eコイン付与を正式ルールに修正（108円ごと1コイン・特販と単品は対象外）`

## タスク2：通し割引の判定を正式ルールに修正

現状：同一title（同じ料理）の合計数量が5以上で適用（＝1日の料理を7個買っても適用されてしまう。誤り）
正式ルール（簡易要件定義書01「通し注文適用ルール」）：

1. 判定単位は**シリーズ（コース）×週**。同一シリーズの商品を、**週内の5日間または6日間**（＝異なるお届け日が5日か6日）注文していること
2. カット野菜の有無（楽シリーズ）が混在してもOK＝同一シリーズ扱い
3. 利用人数が混在してもOK
4. **対象は★印コース＝ミールキット系（cat が smile / more / lovyu）のみ**。tanpin・special は対象外

実装：

- シリーズ（`tag`。楽◯◯は◯◯と同一シリーズに正規化）×週ごとに、カート内の異なる `day` の数を数え、5以上（上限6）ならそのシリーズの対象商品合計に割引適用
- 割引額はモックのため従来どおり「対象合計の5%（10円未満切り捨て）」を維持。関数コメントに「本実装では通常価格と通し割引価格（基幹menu.urine2）の差額合計に置き換える」と明記
- カート・完了・履歴・まとめて購入の表示文言は「通し割引（週5日以上）」とする
- まとめて購入セット（5日分一括投入）で割引が付くこと、単一日の商品を数量7にしても**割引が付かないこと**を確認
- コミット：`fix: 通し割引を正式ルールに修正（シリーズ単位・週5〜6日・単品特販対象外）`
