# 統合指示：origin/main（別端末のエリア判定実装）との合流（2026-07-28）

対象リポジトリ：/Volumes/kei/【SMB】Doc/ヨシケイDoc/yoshikei-B
現状：ローカル main は origin/main より9コミット先行（7項目実装＋docs＋ロゴ）。origin/main には別端末による5コミット（オンボーディングのステップ0エリア判定一式）があり、index.html が両系統で編集されている。

## 統合方針（竹内さん決定）

- **エリア判定（ログイン後のステップ0まわり）は origin/main 版を正とする**。ローカル側（コミット cf69fa6 で入れた実装）は破棄し、リモート版に置き換える
- **ローカルの他の実装はすべて維持**：通し割引／特販の独立ページ型＋A/B切替／レシピ外部明示／かんたんな使い方／絞り込みパネル／細部掃除／ロゴ差し替え
- lp.html はリモートに変更がないため何もしない

## 手順

1. `git merge origin/main` を実行（index.html が競合するはず）
2. index.html の競合解消：
   - ステップ0（エリア確認）に関するデータ・関数・画面・文言は**リモート版のコード**を採用（AREA_ZIPS等のデータ、判定関数、エリア内結果画面、エリア外ガイド画面、デモ用郵便番号の案内、`assets/area_ng.svg` のお詫びイラスト配置を含む）
   - ローカル版のエリア判定コード（cf69fa6 由来）は残骸が残らないよう完全に除去（同名・類似の変数や関数が二重定義にならないこと）
   - それ以外の箇所（通し割引・特販切替・レシピ・使い方・絞り込み・記号掃除）はローカル版を維持
3. `assets/area_ng.svg` はリモート版をそのまま取り込む
4. 解消後、ブラウザなしで実行できる範囲の構文チェックと、フェイクDOMでの render 全状態実行を行い、実行時エラーがないこと・二重定義がないことを確認
5. マージコミットのメッセージ：`merge: エリア判定を別端末版に統一し7項目改修と統合`
