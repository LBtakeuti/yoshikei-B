竹内さん指示：お届けエリア確認バナーを、**未ログイン雑誌型トップのヒーローセクションの直下にも**入れる。**表示サイズは1/2・アスペクト比2:1のまま**。

作業前に必ず `git pull`。1タスク=1コミット。

## 仕様

1. 位置：雑誌型トップの**ヒーローの直後**（バナーカルーセルの手前）。SP・PC両方
2. サイズ（アスペクト比2:1を維持）：
   - **PC**：幅600px（画像原寸1200相当の1/2）で中央寄せ。高さは自動（300px相当）
   - **SP**：コンテンツ幅いっぱい（左右の既存padding内）。高さは幅の1/2（aspect-ratio:2/1）
3. 画像の出し分け：SP=`area-banner-sp.png`（リード文入り）／PC=`area-banner-pc.png`
4. クリック/タップで `Area.open()`（エリア確認モーダル）。role=button・cursor:pointer・alt="お届け対象エリア内か確認する"
5. 表示条件は既存のエリアバナー類と同じ：**未ログイン かつ エリア未確認（rk_area_checked なし）のときのみ**。確認済み・ログイン済みでは出さない
6. 既存の配置（PC=ご利用の流れ直後のバナー／SP=下部追従バナー＋ピル）は**そのまま残す**（今回は追加）
7. 差分描画（morph）対応：出現/消滅で隣が巻き添えにならないよう `data-mk` を付与（既存実装の流儀に合わせる）

## 検証観点（実装後に自分でも確認）

- SP：ヒーロー→エリアバナー→バナーカルーセル…の順に並ぶ。幅いっぱい・高さは幅の半分
- PC：同位置に幅600px中央寄せで表示
- タップでモーダルが開く／エリア確認完了後は消える
- ヒーローのクロスフェード・カルーセル・下部追従バナーに影響なし
