# FB 2026-08-05(2)：PCカルーセルの崩れ修正＋LPフッターの移植

## 修正1：PCカルーセルのレイアウト崩れ（ユーザー報告・スクリーンショットあり）

約2000px幅のPCで確認された症状：
- バナーが中央に来ず、左に大きな余白ができる
- 右側の次バナー（peek）が画面端で中途半端に切れる
- 左右矢印がバナーの内側（テキスト付近）に浮いて文字に重なる
- 全体の幅が制御されておらず、ワイド画面でバナーが巨大化する

### 直し方
- **PCではカルーセル全体に最大幅を設ける**（既存モックのPCコンテンツ幅に合わせて中央寄せ。例：max-width 1200px 前後）。ワイド画面でもバナーがこの幅を超えない。
- **アクティブなバナーをコンテナ中央に配置**し、peek（隣がちら見えする演出）を出すなら左右均等に。難しければ**PCはpeekなしの1枚表示**で良い（peekはSPのみ）。シンプルさ優先。
- **左右矢印はカルーセルの左右端・上下中央に固定**（バナーの外側または端に重なる程度。キャッチコピーの文字には重ねない）。
- ウィンドウリサイズ時に再計算して崩れないこと。1280 / 1536 / 2000px 各幅で確認。
- 位置計算の実測ベース（getBoundingClientRect）は維持して良い。

## 修正2：LPフッターを index.html（未ログイン時）に適用
- `lp.html` のフッター一式（HTML構造＋関連CSS）を `index.html` に移植し、**未ログイン時（雑誌型トップ・フルメニュー表示の両方）**でページ最下部に表示する。
- ログイン済み画面は現状維持（変更しない）。
- リンク先・文言はLPと同一。id重複やCSS衝突に注意（クラス名はLP側と共通化して良い）。
- SP・PC両対応（LP側と同じレスポンシブ挙動）。

## 検証観点（実装後にこちらで確認します）
- PC 1280 / 1536 / 2000px：バナー中央寄せ・最大幅内・矢印が文字に重ならない・横スクロールなし
- SP 390px：従来どおりスワイプ・peek・ドットが動く（回帰）
- 未ログインの雑誌型トップとフルメニュー表示の最下部にLPと同じフッターが出る／ログイン済みには出ない（現状維持）
