# 実装指示：ヒーローのスクリム（ぼかし・オーバーレイ）を軽減（2026-08-05）

対象：`index.html` のヒーローセクション（heroHTML）。lp.htmlは触らない。
竹内さん指摘：**写真の上にかかっているスクリム／オーバーレイが強すぎて写真が見えない**。

作業前に必ず `git pull`。1タスク=1コミット。

## 仕様

1. ヒーロー写真の上のスクリム（クリーム色のグラデーション等）を**大幅に軽くする**：
   - 写真の右側〜中央は**ほぼ素の写真が見える**こと（オーバーレイ透過0〜10%程度）
   - テキストが乗る左側だけ、読める最低限のグラデーションを残す（例：左端 rgba(251,247,238,.85)→40%位置で透明。現状より幅も濃度も絞る）
   - blur系のフィルターがかかっていれば外す
2. SP（写真の上にテキストが重なる構図の場合）：テキスト直下のみ細くグラデーションを敷くか、テキストに `text-shadow`／半透明の帯で可読性を確保し、写真全体は覆わない
3. 見出し・バッジ・締切表示・CTAの可読性は維持（読めなくなるならテキスト側で対処。写真を濁す方向に戻さない）
4. クロスフェード（hero-xfade）・object-positionは変更しない

## 検証観点

- SP/PCとも写真の被写体（子どもの顔・親子）がはっきり見える
- テキストは読める
- 6秒クロスフェードが従来どおり動く
