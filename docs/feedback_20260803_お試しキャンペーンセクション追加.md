# FB 2026-08-03：LPヒーロー直下に「お試しキャンペーン」セクションを追加

## 目的
claude.ai/design で作成した「TrialCampaignSection」を静的HTML化したものを、LP（lp.html）のヒーローセクション直下に配置する。お試しキャンペーンは新規（未会員）向け訴求のため、未ログインの入口であるLPに置く。

## 作業内容（1コミット）
1. `lp.html` を開き、HERO セクションの閉じタグ `</section>`（`<!-- ======================= BRAND CONCEPT ======================= -->` コメントの直前）と BRAND CONCEPT コメントの間に、`docs/snippets/trial_campaign_section.html` の内容を**そのまま丸ごと**挿入する。
   - スニペットは自己完結（scoped な `.tcamp-` クラス＋専用 style ブロック＋モーダル込み）。既存CSS・JSへの変更は不要。
   - 挿入位置の目印：lp.html 内で HERO セクションが終わる `</section>` は1箇所のみ（`data-section="hero"` のセクション）。
2. 画像2点は追加済み（未コミット）。同じコミットに含める：
   - `assets/otameshi-title.png`（お試しキャンペーンタイトル）
   - `assets/yoshikei-san.png`（マスコット）
3. `docs/snippets/trial_campaign_section.html` と本MDもコミットに含める。

## 仕様メモ
- 富山・石川・岐阜ボタン → `index.html?login=1`（現行の「ログイン/はじめての方」モーダル経由で仮登録フローへ）。お試しキャンペーン専用ページ実装後に差し替え予定（スニペット内コメント参照）。
- 愛知ボタン → 配達可能エリア案内モーダル（`#tcampAichiModal`）を表示。オーバーレイクリック・×・OKで閉じる。
- 絵文字・装飾記号は不使用（SVGのみ）。フォントは既存読み込み済みの Zen Kaku Gothic New / Zen Maru Gothic を使用。
